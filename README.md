# CSE 210B — Winter 2027

## SE + PL in the Age of AI: Engineering Formally Verified Software with LLMs

**UC Santa Cruz · Winter Quarter 2027 · Tuesdays & Thursdays**

CSE 210B is a graduate topics course covering different material each
offering. This offering examines how large language models are reshaping
software engineering and programming languages research — with a particular
focus on a hypothesis borne out by recent experience: **LLMs have dropped the
cost of formal verification by one to two orders of magnitude**, making
formally verified software systems practical at scales that were previously
unthinkable.

The course is run as a reading seminar. Each meeting centers on one research
paper, presented by a student and discussed by the class. Students submit
discussion questions before each meeting, and complete a quarter-long project
building a formally verified artifact with LLM assistance.
